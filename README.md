# Entity Nature Verification (ENV): Dissertation Evidence

This repository contains the final supplementary documentary evidence supporting the MSc Cyber Security Management dissertation on Entity Nature Verification (ENV) at the University of Warwick.

## Repository contents

- `ENV_Documentary_Evidence_Matrix_Submission_v1.1.xlsx` — the definitive documentary evidence matrix used to support the dissertation.

## Evidence scope

The matrix documents 146 records identified during the documentary research process. Following eligibility assessment, 143 records were retained: 121 analytical sources, 18 contextual sources and 4 methodology references.

A total of 71 sources were used in the dissertation: 59 analytical contributions, 8 contextual citations and 4 methodology references. The remaining 72 retained records document the breadth of the search but were not used as evidence in the final analysis.

## Important note

This repository provides the documentary audit trail supporting the research. The submitted dissertation remains the authoritative account of the research design, analysis, findings, limitations and proposed Entity Nature Verification model.
